4. Developer Terminology

HTML
HTML is used to create the structure of web pages.
CSS
CSS is used to style web pages.
DOM
DOM represents the structure of an HTML document.
API
API allows different software applications to communicate.
JVM
JVM executes Java bytecode.
JDK
JDK provides tools required to develop Java applications.
SQL
SQL is used to manage and retrieve data from databases.
Git
Git is a version control system.
Java
A programming language.
It is widely used for backend application development.
